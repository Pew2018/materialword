## 阶段完成范围

1. **进度完整性**：一致事务导出事件与全部 learningStates 字段；保存算法版本 2 和事件摘要；
   v5 起核对状态与既有纯事件重放。合并去重事件并重放，不按状态 updatedAt 覆盖。
   重置/撤销事件语义保留。快照恢复在保护性备份后同事务写回验证后的原始状态，失败回滚，成功暂停同步。
2. **设备偏好隔离**：新备份/同步/学习包不含外观、TTS 或常亮设置；所有旧备份恢复忽略它们。
   重新导出旧副本也过滤设备偏好和未知连接字段。每日目标/复习上限/模式/冲刺计划保留。
3. **默认学习 ZIP**：三种内容格式均携带 manifest、progress、sources；范围过滤、多书归属、
   共享词条去重；预览后可仅导入内容或合并进度。路径、条目、大小、CRC、SHA-256、协议及状态校验。
   文档测试发现并修复裸多词书 CSV 丢失共享单词第二个归属的问题。
4. **词库**：默认 ECDICT 26,282→57,835 条；扩展 722,442 条，支持安装/启停/卸载、校验和续传。
   共享清单与本机文件分开；实际词书内容随备份保存。完整离线迁移包含所需资源本体。
   上游提交、许可、规模及未采用来源见 [来源审计](dictionary-sources.md)。
5. **云历史删除**：单条删除无“最近两份”限制；批量完整列举、稳定排序、校验保留项，
   确认后重新核对目标/列表/保留内容，保留两份。上传失败、配置变化、分页不完整时停止。
   互斥、部分失败、权限不足及结果待确认均单独处理；删除后刷新确认。测试未删除真实云端对象。
6. **文档与示例**：README 重写，8 个可直接导入的示例；代码块和文件均实际解析，
   三种学习包往返。源文件支持 UTF-8、别名、引号/换行、多词书和 HTTPS。
7. **UI**：复用经典 MD2 主题、设置行、按钮、确认框；增加中英文、放大文字、窄屏和键盘检查。
   [渲染证据与验收边界](ui/incremental/README.md)。

## 协议与限制

最终备份/同步 v6，用户数据库 Schema 3。v1–v4 无状态文件从事件重建；v5 完整进度继续可读；
v6 新增共享词典选择。过新/不支持算法、损坏摘要及不一致状态拒绝。
状态 updatedAt 为非负记账时间，不参与调度重放校验；快照保留其原值。
算法 1/2 的事件继续按既有规则重放；内容哈希稳定排序并映射逻辑词条身份。

学习包只支持应用生成的不压缩 ZIP，8 MiB/四文件；普通词书导入 20,000 条。
全量备份 JSON 上限沿用各入口原有保护（外部备份/云备份 100 MiB）；完整离线包 200 MiB。
WebDAV 私有分页/已声明限制明确拒绝；不声明的静默服务端截断不能由标准协议推断。
S3 版本控制只执行无 versionId 的普通 DELETE，不清除历史版本。
资源版本不可用时明确提示；大型离线包移动设备内存与真实云权限仍未真机验收。

## 验证方法

各阶段先定向测试，再差异检查。新增有进度协议、设备偏好、学习包、词典、删除、示例和 UI 测试。
性能测试直接插入事件后先重建状态，确保基准快照遵守同一协议契约。
运行项目格式、分析、Drift/l10n 生成、完整回归、跨时区重放及 Android ARM64 release 构建。
本机仅 Command Line Tools，缺完整 Xcode；本机 macOS/iOS 构建失败日志据实保留，不修改原生配置。
最终提交对应的 CI SHA、构建和产物结果以最终交付报告为准。
