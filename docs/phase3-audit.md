## 已确认的根因

- 词汇管理查询固定 limit=300，没有后续分页入口；搜索无异步代际保护。
- 加入词书使用 picked ?? target，取消会回退默认词书继续写入。
- markMastered 经普通认识算法推进且计入正确率，无法保证掌握状态。
- WebDAV 去掉 ETag 引号，正则解析 XML，且同主机 HTTP 降级/端口重定向可带认证。
- GET 后单独获取 PROPFIND ETag，内容与并发令牌没有一致性保证。
- 共享设置首次判断发生于导入词条后，通常不能生效，也缺少版本及模式恢复。
- 内容哈希依赖设备本地 UUID，逻辑相同的数据反复上传。
- 备份表分别读取，可能导出跨写入边界的数据集。
- 当前 Flutter SDK 的 Android 默认是 PredictiveBackPageTransitionsBuilder，MD2 开关不能替代明确转场配置。
- promptForText 在 pop Future 返回时 dispose controller，早于退出动画销毁输入框。
